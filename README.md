# TalkChief Phone for Odoo 20.0

TalkChief in Odoo's top bar: make and answer TalkChief calls without leaving Odoo, and put any
phone number you click into the TalkChief dial pad.

- Module: `talkchief_phone` (version 20.0.1.1.1), no Python code.
- Setup guide: https://docs.talkchief.io/integrations/odoo
- Website: https://talkchief.io

This repository is published automatically for the Odoo Apps store; please don't open pull
requests here. For help, contact TalkChief support at support@talkchief.io.
